# 首次部署指南（GitHub + Cloudflare Pages，全免费）

按顺序做完即可上线。

---

## 一、本地跑起来

1. 安装 [Node.js](https://nodejs.org/)（LTS 版本，≥18）
2. 在本文件夹打开终端（PowerShell），运行：

```powershell
npm install
npm run dev
```

浏览器打开 `http://localhost:4321`，能看到网站即成功。

---

## 二、推送到 GitHub

1. 注册/登录 [GitHub](https://github.com/)
2. 新建一个仓库（Repository），名字如 `product-site`，私有或公开都行
3. 在项目目录执行（把地址换成你的仓库地址）：

```powershell
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/你的用户名/product-site.git
git push -u origin main
```

---

## 三、连接 Cloudflare Pages

1. 注册/登录 [Cloudflare](https://dash.cloudflare.com/)
2. 左侧菜单 → Workers & Pages → Create → Pages → Connect to Git
3. 授权并选择刚才的仓库 `product-site`
4. 构建设置：
   - Framework preset: `Astro`
   - Build command: `npm run build`
   - Build output directory: `dist`
5. 点 Save and Deploy

等待 1-2 分钟，部署完成。你会得到一个免费网址：

```
https://product-site.pages.dev
```

以后每次 `git push`，都会自动重新部署。

---

## 四、（可选）绑定自己的域名

1. 在 Cloudflare Pages 项目 → Custom domains → 添加你的域名
2. 按提示到域名商处修改 DNS
3. 域名费用约 ¥30-60/年（不是必须）

---

## 五、上线后要做的小配置

打开 `astro.config.mjs`，把 `site` 改成你的实际网址：

```js
site: 'https://product-site.pages.dev',
```

---

## 常见问题

**Q: 构建失败？**
看 Cloudflare 里的构建日志，通常是 JSON 格式写错了（多/少一个逗号）。

**Q: 固件文件在哪？**
不放仓库里（免得仓库变大），放 GitHub Releases，网站通过链接引用。

**Q: 想改产品信息？**
编辑 `src/data/products.json` 和 `src/data/site.json`，提交即可。
