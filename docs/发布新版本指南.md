# 发布新版本指南

发布一次固件/软件的完整流程（约 3 分钟）。

---

## 一、打包与命名

文件名建议规范：

```
can-analyzer_firmware_v1.2.0.bin
can-analyzer_software_v1.2.0.exe
```

文件名里带上：产品 + 类型 + 版本号。

---

## 二、上传到 GitHub Releases

1. 打开你的 GitHub 仓库页面
2. 右侧点击 Releases → Create a new release（或 Draft a new release）
3. Tag 填版本号，例如 `v1.2.0`（点 "Create new tag"）
4. Title 填，例如 `车载网络检测仪 v1.2.0`
5. 把固件/软件文件拖进附件区域
6. 点 Publish release

发布后，每个文件都有一个下载链接，形如：

```
https://github.com/你的用户名/你的仓库/releases/download/v1.2.0/文件名
```

把这个链接复制下来。

---

## 三、更新网站版本清单（两种方式任选）

### 方式 A：用辅助脚本（推荐，不用手改 JSON）

在项目目录运行：

```powershell
node scripts/release.mjs
```

按提示依次输入，脚本会自动写入 `downloads.json`。

### 方式 B：手动编辑

打开 `src/data/downloads.json`，在对应产品的 `firmware` 或 `software` 数组开头加一条：

```json
{
  "version": "v1.2.0",
  "date": "2025-06-01",
  "file": "can-analyzer_firmware_v1.2.0.bin",
  "url": "https://github.com/你的用户名/你的仓库/releases/download/v1.2.0/can-analyzer_firmware_v1.2.0.bin",
  "size": "30 MB",
  "sha256": "可留空的校验值",
  "notes": "修复XX问题，提升稳定性"
}
```

---

## 四、提交并发布

```powershell
git add .
git commit -m "release v1.2.0"
git push
```

推送后 Cloudflare Pages 会自动重新构建并上线（约 1 分钟）。

---

## 五、本地预览（可选）

改完想先看看效果：

```powershell
npm run dev
```

浏览器打开 `http://localhost:4321`。

---

## 计算 SHA256（可选，用于校验）

PowerShell：

```powershell
Get-FileHash .\你的文件.bin -Algorithm SHA256
```

把结果填进 `sha256` 字段（可选）。
