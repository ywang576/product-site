把产品图片放在这个文件夹里。

命名建议（英文或拼音，不要用中文和空格）：
  diagnostic-1.png      教学积木 主图
  diagnostic-2.png      教学积木 副图
  can-analyzer-1.png    检测仪 主图
  can-analyzer-2.png    检测仪 副图

支持的格式：.png / .jpg / .jpeg / .webp （推荐 png 或 jpg）
建议宽度 1200px 左右，单张不要超过 2MB（太大网站会变慢）。

然后在 src/data/products.json 里给产品加 "images" 字段，
和 "logo" 字段即可自动显示。详见 README。
